## Documentation

### 📚 Managing Books
- Adding books with covers (uploading images)
- Editing and deleting books
- Automatic ISBN search (Google Books API) (under development)
- Fields: title, author, ISBN, genre, series, publisher, year of publication, number of pages, storage location, link to the electronic version

### 🖼️ 3 catalog viewing modes
| Mode | Description |
|-------|----------|
| **Cards** | Visual preview with covers |
| **Table** | All data in table format |
| **Gallery** | Large covers for quick searching (only the title and cover are visible) |

### 🔎 Search and sort
- Search by title, author, ISBN, genre, series, publisher, storage location
- Sort by any field (ascending/descending)

### ⚙️ Settings
- Change library name
- Choose theme (light/dark)
- Set the number of books per page
- Export data (JSON/CSV)
- Import data from backup

### 🔒 Security
- Data is stored in JSON files
- Easy installation

## Installation
You must have [**project dependencies**](https://github.com/2010-hub/home-library-desktop#dependencies) installed

**1. Download the app**

Download the appropriate [**application release**](https://github.com/2010-hub/home-library-desktop/releases) . Each update includes an **application installer** (requires installation on a PC), a **portable version** (works without installation on a PC), and a **ZIP archive** (needs to be unzipped to the desired folder) for Windows, as well as other file formats for Linux.

**2. Linking a folder**

Open the app. A folder selection window will appear. If you want to use Google Drive sync, select the **Library** folder (for more details, see the [**project dependencies**](https://github.com/2010-hub/home-library-desktop#dependencies)). If you're working locally, go to the **Documents** folder and create a **Library** folder there. Select it in the app.

**3. Done!**

The app itself will now open. You'll have access to all its features. Now you can easily create and catalog your home library.

## Dependencies
This app allows you to sync your library data using **Google Drive Desktop**. Below is a guide on installing Google Drive Desktop. If you want to work locally, skip this instruction.

**1. Installing Google Drive Desktop**

Go to the [**official website**](https://support.google.com/a/users/answer/13022292?hl=en) and download the required version. Install it.

**2. Sign in to your account**

To continue, you need to sign in to your Google account in the Google Drive Desktop app.

**3. Creating a Folder**

Create a **Library** folder in Google Drive (or any other folder you choose)
